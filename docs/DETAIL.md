# 提示词库（Prompt Vault）

> 结论先行：把「能直接复用」的提示词存成一条条可搜索的卡片，并让 agent 在对话里替你提炼、去重、补标签。数据只在本机。

## 它解决什么

提示词散在聊天记录里，用过一次就找不回；同一个提问结构每次都要重打。这个插件做两件事：

1. **存**：侧边栏整页，新建、编辑、标签、常用、搜索、一键复制。
2. **提炼**：agent 通过 `prompt_vault` 工具，从对话里抽出你反复使用的提问骨架，查重后入库；一次最多一条，不写项目细节。

## 怎么用

- 侧边栏点书签图标 → 打开「提示词库」。
- 「新建提示词」：标题写成能力名（如「需求澄清六问」），正文保留【】占位符，标签 2–4 个，备注写什么时候用。
- 卡片上：★ 标常用，点标题展开全文，复制、编辑、删除。
- 直接对我说：
  - 「把刚才那段提示词收藏起来」
  - 「从我们最近的对话里提炼 1 条我常用的提示词」
  - 「我的提示词库里有哪些关于复盘的？」

## 数据在哪

`$DSH_HOME/storages/prompt-vault/vault.json`（默认 `~/.dsh/storages/prompt-vault/vault.json`）。

- 写入是原子的（临时文件 + rename）。
- 文件损坏时自动改名备份为 `vault.json.corrupt-<时间戳>`，然后从空库开始。
- 不联网、不上传；卸载插件不会删这个文件。

## Agent 侧

- 工具 `prompt_vault`：`list` / `get` / `add` / `update` / `remove` / `use`。
- Skill `prompt-vault`：提炼规则（收什么、不收什么、怎么命名）。
- 每轮系统提示里有一句话提醒它在合适时机使用，不必等你说出「插件」两个字。

## 边界

- 点「复制」只写入剪贴板；本版本无法把提示词直接塞进输入框（Client 没有 composer 注入服务）。
- 只在本机，不做多设备同步。
- 单库上限 1000 条，单条正文上限 20000 字。
- 删除不可撤销；页面会二次确认，agent 不被允许擅自删除。
