## 写作边界

- 用户文档只写「怎么用、边界是什么」，不写内部实现争论。
- 复盘写「决策、代价、证据、可推翻条件」，不写情绪散文。
- 新增文档先挂到本表，再改根 `README.md` 的链接。
- 日期写全（`YYYY-MM-DD`），标题用「主题_类型_日期」。
